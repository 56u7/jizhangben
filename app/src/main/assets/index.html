使用说明
基础操作
＋ 记一笔
半屏表单，默认当天日期；金额支持加减乘除算式，点击其他区域或保存时自动算出结果。
✎ 编辑记录
点任意一条账目，可修改金额、分类、日期、备注。
＋ 常用备注
备注框右侧的灰色加号可选常用备注（点一条即填入，点右侧 × 可删除，也能自己新建）；长按备注框可把框里的内容直接存为常用。记录保存后，12 字以内的备注会自动收进常用，最多保留 20 条。
↔ 左滑标记 · 右滑删除
左滑可标星或取消标星；右滑整条会弹出删除确认。
⏱ 长按不计入预算
长按记录约 0.5 秒，切换是否计入今日预算。
☑ 批量选择与删除
长按列表上方的“本周 / 本月”，可批量勾选并删除多条账目。
视图
▤ 借出借入 / 明细 / 日历 / 统计
四个入口同排；明细显示累计结余和每日预算；日历中选中日期为蓝色实心，下面显示当日预算和记录，可用蓝色加号记一笔；统计显示预算超支、分类占比和月度对比。
借出借入
借 借出 / 借入
记录借出、借入、约定还款日和部分还款；逾期未还会在入口显示蓝点；借款会影响累计结余和当前结余模式，但不计入收入、支出、分类统计和超支汇总。
每日预算
¥ 本月收入 / 当前结余
当前结余按剩余天数或自定义天数分摊；借出会减少累计结余，收回会增加，借入会增加，归还会减少，但都不计入本月收入、支出和分类统计。
数据
捕 支付信息自动捕获
开启并授予通知使用权后，微信 / 支付宝支付及交易提醒通知先进“待导入账目”；点账目可先修改，也支持右滑标星、左滑删除、长按不计入，确认导入后状态会保留。
导 导入微信 / 支付宝账单
自动识别微信或支付宝导出的 xlsx / CSV 账单文件，预览确认后写入账本。
清 清理导入账单
按来源和月份清理微信 / 支付宝导入的账目，不影响手动记录。
CSV 导出 Excel / CSV
把账目明细导出为表格文件，方便查看或备份。
备 完整备份与恢复
账目、分摊设置、显示设置、待导入账目和借出借入记录都会一起备份，建议换机前导出。
