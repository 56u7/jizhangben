使用说明
基础操作
＋ 记一笔
点击底部“记一笔”，默认当天日期，可选择支出/收入。
✎ 编辑记录
点任意一条账目，可修改金额、分类、日期、备注。
↔ 左滑标记 · 右滑删除
左滑可标星或取消标星；右滑整条会弹出删除确认。
⏱ 长按不计入预算
长按记录约 0.5 秒，切换是否计入今日预算。
☑ 批量选择与删除
长按列表上方的“本周 / 本月”，可批量勾选并删除多条账目。
视图
▤ 明细 / 日历 / 统计
明细按周或月查看；日历看每天圆点；统计看分类占比和月度对比。
每日预算
¥ 本月收入 / 当前结余
当前结余默认按剩余天数分摊，天数可自定义，也可恢复。
数据
捕 支付信息自动捕获
开启并授予通知使用权后，微信 / 支付宝支付及交易提醒通知先进“待导入账目”；点账目可先修改，也支持右滑标星、左滑删除、长按不计入，确认导入后状态会保留。
导 导入微信 / 支付宝账单
自动识别微信或支付宝导出的 xlsx / CSV 账单文件，预览确认后写入账本。
清 清理导入账单
按月份清理微信 / 支付宝导入的账单，不影响手动记录。
CSV 导出 Excel / CSV
把账目明细导出为表格文件，方便查看或备份。
备 完整备份与恢复
账目、分摊设置、显示设置与待导入账目都会一起备份，建议换机前导出。
